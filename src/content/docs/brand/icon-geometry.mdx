本规范定义 Elysola 普通版与装饰版图标的几何参数、构造方法、工程制图要求与验收标准。除特别说明外，所有尺寸均为局部坐标单位。

## 1. 总则

### 2.1 构图定义

Elysola 图标包含普通版和装饰版两种构图。两种版本均采用横向字标构图，并须保持本规范规定的局部画布比例。

- **普通版**：由紧凑并排的 `ES` 字标、贯穿前景的地平线透镜，以及位于透镜上方的负空间切槽组成。
- **装饰版**：由横向舒展排列的 `E`、居中的太阳与地平线透镜，以及右侧的 `S` 组成。太阳和地平线透镜共同桥接 `E` 与 `S`。

### 1.2 坐标系与画布映射

两种版本分别使用独立的局部坐标系。图形构造完成后，再整体映射至 `512 × 512` 的最终画布。

局部坐标系约定如下：原点位于局部画布左上角，`+x` 轴向右，`+y` 轴向下。工程蓝图中，小网格间距为 10 个局部单位，大网格间距为 50 个局部单位。

| 项目 | 普通版 | 装饰版 |
| --- | ---: | ---: |
| 局部画布 | `280 × 140` | `360 × 140` |
| 图形外接框 | `x: 24–256`，`y: 22–128` | `x: 26–328`，`y: 24–128` |
| 竖向中轴线 | `x = 140` | `x = 180` |
| 地平线基准轴 | `y = 98` | `y = 88` |
| 太阳基准轴 | — | `y = 66` |
| 映射至最终画布 | `translate(32, 136.8) scale(1.6)` | `translate(36.3, 169.3) scale(1.22)` |

最终映射应保持图形比例，不得进行非等比缩放、旋转或裁切。

### 1.3 圆弧定义

全图曲线统一采用圆弧定义。每段圆弧由起点 `P₀`、弧中控制点 `Pc` 和终点 `P₂` 三点确定。坐标、半径、圆心和圆心角统一保留 1 位小数；`S` 轮廓各段的起点、过点和终点保留 2 位小数，末位为 0 时可省略至 1 位。所有计算必须使用未取整的原始值，取整仅用于最终显示。

- 三点二次插值曲线的中点：`P(0.5) = (P₀ + 2Pc + P₂) / 4`。
- 设弦长为 `L`、矢高为 `h`，则圆弧半径和圆心角分别为：
  - `R = ((L / 2)² + h²) / (2h)`
  - `θ = 2 · asin((L / 2) / R)`

除非另有说明，本文中的角度均以度（°）为单位，长度均以局部坐标单位为单位。

## 3. 共用参数

下列参数适用于普通版和装饰版。除第 5.1 节明确说明的装饰版 `E` 横画参数外，同一参数在两个版本中必须使用同一数值。

| 符号 | 数值 | 定义 |
| --- | ---: | --- |
| `t` | 18 | 标称笔画厚度；用于普通版 `E` 横画及 `S` 轮廓 |
| `r` | 9（`t / 2`） | `E` 横画右端半圆半径 |
| `r₀` | 6（`t / 3`） | `E` 脊柱左上角、左下角的外圆角半径 |
| `g` | 6 | 负空间切槽的形成宽度；原始遮罩透镜的描边宽，切槽带宽按第 4.5 节实际几何形状定义 |
| `R_sun` | 38 | 装饰版太阳半径 |
| `R` | 按弧段定义 | 各圆弧的半径 |
| `θ` | 按弧段定义 | 各圆弧的圆心角，按第 1.3 节计算 |

## 4. 普通版构造规范

普通版由 `ES` 字标、负空间切槽和地平线前景透镜三部分组成。

### 4.1 绘制顺序

1. 绘制并合并 `E` 与 `S`。
2. 绘制并执行负空间切槽。
3. 绘制最上层的地平线前景透镜。

### 4.2 字母 `E`

字母 `E` 由一个脊柱和三条横画并集构成。

| 部件 | 几何定义 |
| --- | --- |
| 脊柱 | `roundRect(x=42, y=22, w=26, h=96)`；左上角、左下角圆角为 `r₀=6`；右侧两角不倒圆 |
| 上横 | `y=22`，高度 `18`；左端 `x=48`，直线至 `x=124`；右端半圆半径 `r=9`，视觉末端 `x=133` |
| 中横 | `y=61`，高度 `18`；左端 `x=48`，直线至 `x=114`；右端半圆半径 `r=9`，视觉末端 `x=123` |
| 下横 | `y=100`，高度 `18`；左端 `x=48`，直线至 `x=124`；右端半圆半径 `r=9`，视觉末端 `x=133` |

补充约束：三横左端均为脊柱左端加 `r₀`，即 `x=48`；左上、左下圆角必须完整保留。横画直线终点与视觉末端分别计量，端帽位于直线终点之外。三横横距为 `39`，净空隙为 `21`；`E` 与 `S` 的间距为 `16`（按脊柱左端与 `S` 外接框计算）。

### 4.3 字母 `S`

字母 `S` 必须采用闭合填充轮廓构造。普通版 `S` 由 20 段固定圆弧和 2 条固定直线段组成；装饰版使用同一组逐段几何参数，整体向右平移到其规定外接框。绘制时必须严格遵守规范中的段数、顺序、端点、圆心、半径、圆心角、闭合方式和 `nonzero` 填充规则，不得重新拟合或替换为自由曲线。

- 普通版外接框：`x: 129–232`，`y: 22–128`。
- 装饰版外接框：`x: 227–328`，`y: 26–128`。
- 全部轮廓共包含 20 段圆弧和 2 条直线段。

普通版关键端点为：上端面 `(228.0, 41.0) → (216.0, 52.0)`，下端面 `(129.0, 108.0) → (142.0, 94.0)`；腰部横截面为 `x: 172.5–227.0`。装饰版关键端点为：上端面 `(322.0, 43.0) → (311.0, 54.0)`，下端面 `(227.0, 109.0) → (240.0, 95.0)`。完整逐段明细以新版规范第 3.2、4.4 节为唯一依据。

| 项目 | 几何定义 |
| --- | --- |
| 上端面 | 起点 `(228, 41)`，终点 `(216, 52)`，中点 `(222, 46.5)` |
| 下端面 | 起点 `(142, 94)`，终点 `(129, 108)`，中点 `(135.5, 101)` |
| 腰部横跨 | 在 `y=80` 处，横跨 `x: 175–226` |
| 下字怀开口 | 在 `y=110` 处保持开口；墨迹分为 `x: 131–174` 和 `x: 190–226` 两段 |

端面坐标、腰部横跨范围和下字怀开口必须符合上表，不得将下字怀封闭。

### 4.4 地平线前景透镜

地平线透镜由上、下两条圆弧组成。两条圆弧共享同一弦线端点，形成双圆弧透镜形。

| 边界 | 矢高 `h` | 半径 `R` | 圆心角 `θ` | 圆心 |
| --- | ---: | ---: | ---: | --- |
| 上弧 | 27 | 262.7 | 52.4° | `(140, 333.7)` |
| 下弧 | 20.5 | 338.4 | 40.1° | `(140, 415.9)` |

- 弦长：`L=232`。
- 弦线端点：`(24, 98)` 和 `(256, 98)`。
- 透镜中心最大厚度：`6.5`。
- 两个圆心均位于图框下方 200 个局部单位以外；工程蓝图必须标注真实圆心和半径。

### 4.5 负空间切槽

负空间切槽采用加宽透镜形状，基准弦长为 `232`，弦线位置为 `y=97`，端点为 `(24, 97)` 和 `(256, 97)`。

| 边界 | 矢高 `h` | 半径 `R` | 圆心角 `θ` | 圆心 |
| --- | ---: | ---: | ---: | --- |
| 上弧 | 33 | 220.4 | 63.5° | `(140, 284.4)` |
| 下弧 | 26.5 | 267.1 | 51.5° | `(140, 337.6)` |

半径和圆心必须由未取整的原始值计算，表内数值仅为保留 1 位小数后的显示值。
- 相对于前景透镜边界的法向外扩量：`g=6`。
- 切槽必须贯穿 `ES` 字标，不得在字标内部留下残余连接。

切槽可通过离屏图层擦除，或使用背景色绘制同形轮廓覆盖生成。

## 5. 装饰版构造规范

装饰版采用横向舒展构图：`E` 位于左侧，太阳与地平线透镜位于中央，`S` 位于右侧。太阳与地平线透镜的桥接区域为 `x: 86–274`，`S` 的范围为 `x: 227–328`；重叠区的相对位置必须保持不变。

### 4.1 字母 `E`

字母 `E` 由一个脊柱和三条横画并集构成。装饰版横画参数为本规范针对该版本定义的例外参数。

| 部件 | 几何定义 |
| --- | --- |
| 脊柱 | `roundRect(x=26, y=24, w=26, h=92)`；左上角、左下角圆角为 `r₀=6`；右侧两角不倒圆 |
| 上横 | `y=24`，高度 `18`；从 `x=26` 延伸至 `x=104`，长度 `78`；右端圆角半径 `9` |
| 中横 | `y=62`，高度 `16`；从 `x=26` 延伸至 `x=86`，长度 `60`；右端圆角半径 `8` |
| 下横 | `y=98`，高度 `18`；从 `x=26` 延伸至 `x=104`，长度 `78`；右端圆角半径 `9` |

### 4.2 太阳

太阳由一个半圆和一个浅圆弧切口组成。

| 部件 | 几何定义 |
| --- | --- |
| 半圆 | 圆心 `O=(180, 66)`，半径 `R_sun=38`，圆心角 `180°`；直径端点为 `(142, 66)` 和 `(218, 66)` |
| 底部切口 | 底边为浅圆弧；弧中点 `(180, 61)`，矢高 `5`；切口圆半径 `R=146.9`，圆心角 `θ=30.0°`，圆心 `(180, 207.9)` |
| 净高 | `33`；顶部 `y=28`，底部 `y=61` |

### 4.3 地平线透镜

地平线透镜由上、下两条圆弧组成。

| 边界 | 矢高 `h` | 半径 `R` | 圆心角 `θ` | 圆心 |
| --- | ---: | ---: | ---: | --- |
| 上弧 | 21 | 220.9 | 50.4° | `(180, 287.9)` |
| 下弧 | 12 | 374.2 | 29.1° | `(180, 450.2)` |

- 弦长：`L=188`。
- 弦线端点：`(86, 88)` 和 `(274, 88)`。
- 透镜中心最大厚度：`9`。
- 太阳底部切口底部为 `y=61`，位于地平线透镜上弧顶部 `y=67` 之上；两者不得相交。

### 4.4 字母 `S`

字母 `S` 的构造方法与普通版一致：外轮廓和内轮廓逐段采用圆弧拟合，使用直线端面收口，最终作为一个闭合轮廓一次填充。

- 外接框：`x: 227–328`，`y: 26–128`。

| 项目 | 几何定义 |
| --- | --- |
| 上端面 | 起点 `(322, 43)`，终点 `(311, 54)`，中点 `(316.5, 48.5)` |
| 下端面 | 起点 `(240, 95)`，终点 `(227, 109)`，中点 `(233.5, 102)` |

## 6. 工程蓝图制图规范

- 背景色：深蓝 `#0B2A4A`。
- 小网格间距：10 个局部单位；大网格间距：50 个局部单位，并使用加粗线显示；坐标刻度标注在图框外侧。
- 实形：以白色填充轮廓表示字标和实体图形。
- 构造线：使用红色或亮青色虚线，与实形明确区分。
- 每个圆心绘制十字标记，并标注 `O₁`、`O₂`、`O_sun` 等名称；整圆使用虚线绘制。
- 对于圆心位于图框外 200 个局部单位以上的浅弧，只绘制图框内的虚线弧段；半径标注在图框外，并按真实坐标标注圆心位置。
- 使用点划线绘制竖向中轴线：普通版 `x=140`，装饰版 `x=180`。
- 使用点划线绘制地平线基准轴：普通版 `y=98`，装饰版 `y=88`；装饰版额外绘制太阳基准轴 `y=66`。
- 将 `t` 标注在 `E` 的上横上，将 `r` 标注在横画右端，将 `r₀` 标注在脊柱左上角，将 `g` 标注在前景透镜与切槽边缘之间。
- 将各弧的 `R` 和 `θ` 标注在对应弧段两端的扇形区域；使用红色斜线段标出 `S` 的上、下端面，并标注坐标。

## 7. 几何构造约束

- 允许使用的几何基元：正圆、圆弧、圆角矩形、胶囊体、双圆弧透镜和闭合圆弧拟合轮廓。
- 禁止使用贝塞尔曲线和遮罩构造图形。
- 负空间切槽必须通过离屏图层擦除或背景色同形覆盖生成。
- 普通版和装饰版应共用第 2 节定义的参数；同一参数不得在不同版本中使用不同数值，装饰版 `E` 横画的例外参数除外。
- 浅圆弧必须严格按照本规范给出的圆心和半径绘制。

## 8. 验收标准

### 7.1 两个版本分别验收

| 验收项目 | 合格标准 |
| --- | --- |
| `S` 轮廓交并比（IoU） | 与本规范定义的基准轮廓比对，`IoU ≥ 0.95` |
| `S` 端面中点偏差 | 不超过 2 个局部单位；普通版端点为 `(228.0, 41.0)`、`(216.0, 52.0)`、`(129.0, 108.0)`、`(142.0, 94.0)`；装饰版端点为 `(322.0, 43.0)`、`(311.0, 54.0)`、`(227.0, 109.0)`、`(240.0, 95.0)` |
| `S` 腰部与下字怀 | 普通版在 `y=80` 处横跨 `x: 175–226`；在 `y=110` 处保持两段开口，不得封死 |
| `E` 横画末端 | 普通版依次为 `x=124 / 114 / 124`；装饰版依次为 `x=104 / 86 / 104` |
| `E`—`S` 间距 | 普通版为 `16` |
| 构图关系 | 普通版切槽贯通；装饰版太阳切口位于地平线透镜上方；局部画布比例保持为 `280:140` 和 `360:140` |

### 7.2 公差

- 地平线弧线拟合偏差：不超过 `0.8` 个局部单位。
- 太阳轮廓偏差：`0`。
- `E` 的各部件：以第 3.2 节和第 4.1 节的数值为准。
- `S` 的端面和腰部：遵循第 7.1 节规定的公差。
