Elysola 不使用一份透明单色 SVG 覆盖所有场景。应根据显示尺寸、背景环境和版式需求，选择对应的品牌资产。

## 资产清单

| 资产 | 文件 | 主要用途 |
| --- | --- | --- |
| 默认主图标 | `projects/elysola/icon.svg` | 网站卡片、应用图标、社交头像，以及 48px 及以上的常规展示 |
| 小尺寸图标 | `projects/elysola/icon-small.svg` | 16px、32px、favicon、紧凑导航和小型状态区域 |
| 单色标志 | `projects/elysola/icon-mono.svg` | 内联 SVG、单色印刷，以及由宿主明确控制前景色的界面 |
| 装饰标志 | `projects/elysola/icon-decorative.svg` | 大尺寸品牌装饰、海报和非功能性视觉；不得用作应用图标 |
| 横排字标 | `projects/elysola/icon-text.svg` | 页眉、品牌署名和空间充足的横向版式 |

## 选择规则

### 默认使用 `icon`

没有特殊要求时，使用彩色 `icon.svg` 或对应 PNG。该资产使用蓝色圆角底板和白色标志，在浅色、深色及复杂背景上都具有稳定的对比度。

适用场景：

- 产品卡片和项目列表；
- GitHub、社交平台和聊天机器人头像；
- PWA、桌面应用和移动应用图标；
- Open Graph 图片中的品牌图标；
- 48px 及以上的独立图标展示。

不得通过 CSS 为该资产重新着色，也不得移除其底板。

### 16px 和 32px 使用 `icon-small`

小尺寸图标经过光学校正，放大并加粗了 `ES`，并简化了容易被抗锯齿吞掉的细节。以下场景必须使用 `icon-small.svg`：

- 16px、32px PNG；
- 浏览器 favicon；
- 紧凑导航、菜单、标签和小按钮；
- 实际显示尺寸不超过 32 CSS px 的位置。

VectorLoom 已自动执行尺寸切换：正式的 `output/elysola/icon-16.png` 和 `icon-32.png` 来自 `icon-small.svg`；48px 及以上的输出来自 `icon.svg`。使用仓库生成的 PNG 时，无需手动选择源文件。

SVG 消费方不会根据显示尺寸自动切换源文件。直接引用 SVG 时，应通过 `<picture>`、媒体条件或组件逻辑，在显示尺寸不超过 32px 时选择 `icon-small.svg`。

### 需要主题着色时使用 `icon-mono`

单色版为透明背景，并使用 `currentColor`。它只适用于宿主能够明确控制前景色的场景：

- 内联到 HTML 或组件中的 SVG；
- 浅色背景上的深色单色标志；
- 深色背景上的白色或浅色标志；
- 单色印刷、压印、激光雕刻和水印。

推荐颜色：

```css
.elysola-mark {
  color: #172033;
}

.dark .elysola-mark {
  color: #f5f7fb;
}
```

`currentColor` 只有在内联 SVG 或组件化 SVG 中才能可靠继承。不要使用普通的 `<img src="icon-mono.svg">` 并期待它继承父元素颜色；这种用法通常会回退为黑色。

如果无法内联，应使用彩色默认图标，或由消费方生成固定颜色版本。单色版不适合 favicon、头像或无法控制背景的外部平台。

### 横向空间充足时使用 `icon-text`

横排字标用于需要同时表达图形与名称的场景：

- 网站页眉和品牌导航；
- 合作伙伴页与赞助署名；
- 文档首页和演示文稿标题；
- 横向品牌锁定组合。

字标是按宽度驱动的非正方形资产。只设置目标宽度，高度必须由 `viewBox` 比例派生；禁止同时强制相同宽高。

当显示空间狭窄或高度低于约 32px 时，应优先使用方形主图标或小尺寸图标。

### `icon-decorative` 只用于大尺寸装饰

装饰版保留更舒展的几何关系，适合 Hero、海报、背景图形和品牌展示。它不具备统一底板，也未针对小尺寸进行优化，因此不得用于：

- favicon；
- 应用图标；
- 头像；
- 按钮；
- 紧凑导航。

## 网站使用建议

| 场景 | 推荐资产 |
| --- | --- |
| 网站页眉 | 空间充足时使用 `icon-text`；移动端或紧凑页眉使用彩色 `icon` |
| favicon | 使用仓库生成的 `icon-16.png`、`icon-32.png` 和更高分辨率彩色 PNG |
| 深色模式 | 默认彩色图标无需切换；单色版切换为浅色前景 |
| Hero | 可使用大尺寸 `icon`；需要弱化、铺底或动态着色时使用 `icon-mono` 或 `icon-decorative` |
| 外部平台 | 默认上传彩色 PNG，不上传依赖 `currentColor` 的 SVG |

## 快速决策

1. **显示尺寸不超过 32px？** 使用 `icon-small` 或仓库生成的小尺寸 PNG。
2. **需要宿主控制颜色？** 使用可内联的 `icon-mono`。
3. **需要图形和名称并列？** 使用 `icon-text`，只设宽度。
4. **大尺寸、非功能性装饰？** 可使用 `icon-decorative`。
5. **其他情况？** 默认使用彩色 `icon`。
